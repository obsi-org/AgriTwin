# Dataset Notice

AgriTwin - Agricultural Digital Twin for Intelligent Decision-Making

Copyright 2026 Obsidian Innovation Institute - Associação

The AgriTwin sample dataset package is distribution-safe. It contains anonymised/aggregated records, deterministic synthetic records and schema-only examples compatible with the AgriTwin sensor, DSS, analytics, reporting and Digital Twin architecture.

The dataset records are released under CC BY 4.0. Dataset generation and validation scripts remain under Apache License 2.0.

Raw pilot-farm data, credentials, security secrets, exact private coordinates, site-specific infrastructure identifiers, private thresholds and non-anonymised operational logs are excluded.
