# Schematics and Wiring Guides

The wiring guides describe generic connection patterns for AgriTwin-compatible hardware. They are not PCB manufacturing drawings. Verify voltage levels, pin capabilities, waterproofing, sensor documentation and local safety requirements before installation.

Guides:

- `standard_sensor_node_wiring.md`: Arduino-compatible soil and microclimate node.
- `weather_station_wiring.md`: open weather station and RS485 station options.
- `edge_gateway_wiring.md`: gateway power, networking and field interfaces.

Use deployment-specific credentials and identifiers only through local configuration outside this repository.
