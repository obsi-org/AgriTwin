# Open Hardware Distribution Notes

This folder helps reviewers confirm that the Open Hardware reference package is safe to share.

The package includes:

- generic BOMs;
- generic wiring guidance;
- placeholder-only firmware examples;
- generic JSON Schemas and transport conventions;
- cloud and edge + cloud deployment guidance;
- calibration, testing, safety and privacy notes.

The package excludes:

- real farm coordinates and parcel boundaries;
- private sensor identifiers;
- operational telemetry;
- local credentials and service configuration;
- generated reports and logs.

Run the distribution safety scanner before external sharing.
