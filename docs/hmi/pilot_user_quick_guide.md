# AgriTwin Pilot User Quick Guide

## Daily Check

1. Open the AgriTwin dashboard.
2. Start with Field Overview.
3. Check water stress, irrigation recommendation, pest risk, fertiliser recommendation, and connectivity.
4. Use recommendations marked Normal for routine decisions.
5. Verify locally before acting on Reduced, Stale, or Unavailable recommendations.

## Digital Twin

Use Digital Twin Map when you need parcel context, sensor markers, vegetation overlays, or asset location. The main dashboard is enough for most daily decisions.

## Irrigation

Open Irrigation Schedule to see planned tasks. Check rain and soil moisture before starting irrigation. If OpenAgri Irrigation is stale, use the schedule as guidance and confirm conditions in the field.

## Pest and Disease

Open Pest & Disease Alerts before scouting or treatment. A reduced-confidence alert means service data or local observations need confirmation.

## Offline Use

If the offline banner appears:

- Continue reading the last saved dashboard state.
- New report/export actions are queued locally.
- Wait for connectivity before relying on fresh OpenAgri service data.
- Check the queued operations count after 4G returns.

## Reports

Use Prepare advisory export in Reports / PDF Advisories. The dashboard prepares a safe advisory payload and opens print-to-PDF. Do not attach raw pilot data or private parcel maps to public messages.

## Settings

Use Settings / Connectivity for dashboard settings and offline cache controls. Do not type or share production tokens, farm Wi-Fi secrets, or private operational thresholds in screenshots.
