# Analytics Chart Definitions

Date: 2026-05-13

The analytics page uses local SVG charts generated by PHP. No external CDN or browser dependency is required.

| Chart | Data | Purpose |
| --- | --- | --- |
| Weather multi-line trend | Average air temperature, humidity and wind over selected range | Shows microclimate evolution and operational weather pressure. |
| Rainfall + temperature combination | Rainfall bars and temperature line | Connects precipitation timing with field temperature. |
| Soil moisture trend | Per-station VWC trend | Highlights blocks approaching irrigation thresholds. |
| Soil temperature trend | Per-station soil temperature trend | Supports crop-growth and disease-risk interpretation. |
| Station irrigation-need ranking | Calculated score from soil moisture | Prioritises field inspection and irrigation attention. |
| Water-balance gauge | Water-balance score from soil moisture deficit | Summarises irrigation status in one operational indicator. |
| Pest-risk gauge and trend | Risk index and generated trend points | Shows current category and movement. |
| Service freshness table | OpenAgri status, latency and last check | Separates mandatory services from operational extensions. |

## Thresholds

- Preferred soil moisture target: 28% VWC.
- Watch threshold: 23% VWC.
- Water-balance score: `100 - irrigation_deficit * 12`, clipped to 0-100.
- Irrigation-need score: `(30 - soil_moisture_pct) * 6`, clipped to 0-100.

## Known Limits

Time-series values are derived from the current operational station dataset until longer historical storage is connected. The visual model is deterministic and intended for local validation, not final agronomic certification.
